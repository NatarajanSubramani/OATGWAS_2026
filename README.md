# Identification of germplasm and genomic markers associated with reduced T-2 and HT-2 mycotoxin accumulation in oat

This repository contains data supporting the manuscript:

"Identification of germplasm and genomic markers associated with reduced T-2 and HT-2 mycotoxin accumulation in oat"

## Data structure

- data/field: Field experiment toxin and fungal DNA data
- data/glasshouse: Glasshouse toxin data
- data/gwas: SNP genotype matrix, marker positions, and genotype mapping
